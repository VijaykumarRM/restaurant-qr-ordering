🔧 CONFIGURATION
═══════════════════════════════════════════════════════════════════════════

Default Settings:
  • Admin Password: admin123
  • Restaurant ID: 1
  • Backend Port: 8000
  • Frontend Port: 5500
  • Network: 0.0.0.0 (all interfaces)

Change Admin Password:
  1. Edit: frontend/admin.html
  2. Find: const ADMIN_PASSWORD = "admin123";
  3. Change to: const ADMIN_PASSWORD = "your_password";
  4. Reload admin page

Change Server Ports:
  1. Edit: START.bat
  2. Change: --port 8000 to --port NEWPORT
  3. Change: python -m http.server 5500 to NEWPORT
  4. Run START.bat again
