🎯 HOW TO USE
═══════════════════════════════════════════════════════════════════════════

CUSTOMER JOURNEY
  1. Scans table QR code
  2. Opens menu page
  3. Sees loyalty points balance
  4. Adds items to cart
  5. Optionally redeems points
  6. Places order
  7. Pays
  8. Sees points earned (if ≥₹1000 order)
  9. New balance shown

ADMIN JOURNEY (Setup)
  1. Opens admin dashboard
  2. Scans menu item QR codes
  3. Items auto-fill and publish
  4. Menu built in minutes!

ADMIN JOURNEY (Daily)
  1. Monitors real-time orders
  2. Sees payment status
  3. Refreshes to see latest
  4. Tracks items and totals
